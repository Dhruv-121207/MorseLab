# 📡 Morse Code Translator (Python)

## 🧠 About the Project

This is a small and fun Python project I created when I had just learned the basics of Python.

At that time, I was curious about Morse code and wanted to see if I could build something simple using what I knew — dictionaries, loops, conditionals, and functions. The result is this program that can translate text to Morse code and Morse code back to text.

This project represents my early learning phase and my curiosity-driven approach to programming.

---

## ✨ Features

* Converts English text to Morse code
* Converts Morse code to English text
* Supports:

  * Alphabets (A–Z)
  * Numbers (0–9)
  * Common punctuation
* Uses a dictionary-based mapping
* Simple terminal input and output

---

## 🛠️ Technologies Used

* Python
* No external libraries (pure Python basics)

---

## ▶️ How to Run

1. Make sure Python is installed

2. Clone the repository:

   ```bash
   git clone https://github.com/your-username/morse-code-translator.git
   ```

3. Run the file:

   ```bash
   python morse_code.py
   ```

4. Enter text or Morse code when prompted
